Ningún patrón vale siempre: cada ficha dice cuándo se rompe

Pulsa una ficha para darle la vuelta: señal → mecanismo → efecto para cada parte → condición → excepción → ejercicio de contraste. Un patrón cuenta como transferido cuando lo aplicas bien en dos problemas distintos; un único acierto no basta.
